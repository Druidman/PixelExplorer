# PixelExplorer

Game about building a village for your soldier that help you destroy main turrets in middle

**Game is inspired by `Lordz.io`**

## How to play?
- Download latest release of game from github or `itch.io`
- Extract `.zip` file
- Run `PixelExplorer.exe` (Or just binary on linux)

## Game loop
- Earn coins
- build gold mines
- build other buildings
- spawn soldiers
- attack main towers
- try not to die ;D

## Controls
### Modes
- `b` - build mode
- `z` - attack mode
- `<Regular>` - move mode
#### Regular mode
- mouse guided controls
- To enter this mode from other mode just click button that activates mode you are currently on
**Mode activate buttons work as toggle**
#### Build mode
- `q` - archer tower
- `e` - soldier home
- `m` - magic tower
- `c` - gold mine
#### Attack mode
- Click object you want your soldiers to target
